## Overview

Lianac is an Android application for browsing and reading arXiv (https://arxiv.org) papers. It lets you explore by subject, search articles, bookmark favorites, download PDFs for offline reading, and render LaTeX in article content.

## Features

- **Browse by subjects**: Navigate arXiv categories with a structured hierarchy
- **Search**: Search articles with customizable query options
- **Article details**: View abstracts, authors, metadata, and rendered content
- **Bookmarks**: Save articles for quick access later
- **Downloads**: Download PDFs and manage them offline
- **LaTeX rendering**: Render mathematical formulas in articles
- **Web view**: Open articles in-app via WebView

## Tech Stack

- **Language**: Java
- **UI**: Material Components, RecyclerView, CardView
- **Database**: Room (bookmarks & downloads)
- **Other**: Fragments, custom LaTeX renderer, Toasty

## Status

Lianac was created as a group project for the Mobile Application Development course. Currently, we don't have plan to update or maintain this project. If you see potential in it and would like to develop it further, please open an issue!
